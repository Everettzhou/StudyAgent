# 知序 · 本地学习助手 0.1.11

Windows 本地学习工作台。原始资料与学习记录存入本机 SQLite / 文件库；模型和搜索仅处理经课程授权的任务内容。

## 启动

优先运行 `release/0.1.11/StudyAgent-Setup-0.1.11.exe` 安装，或直接运行 `release/0.1.11/win-unpacked/知序学习助手.exe`。数据位置为 `%APPDATA%/ZhixuStudyAgent`，卸载默认保留学习数据。

开发运行（Node 22.13+）：

```powershell
npm ci
npm run build
npm start
```


## 0.1.11 · 打开即聊与沉浸阅读

- 启动后直接进入学习伙伴，输入框自动聚焦。展开对话选项、引用资料或个人记忆设置时各自在容器内滚动，不再重叠。
- 课程资料打开后点击“沉浸阅读课件”：左侧阅读，右侧与 Agent 对话。文字选区与图表／公式框选均可加入右侧对话，并沿用选区连续追问；支持新对话、回复和分支。
- 课程阅读保存页码、缩放、滚动位置、对话和侧栏宽度，纯阅读与阅读＋对话可切换。课件问答与学习伙伴共用个人学习记忆。
- 论文库优先展示已导入论文，点击即可沉浸阅读。再次打开或重启软件后恢复该论文的页码、缩放及页内滚动位置，并保留对话草稿；不同论文分别保存。
- 阅读进度即时写入本机缓存并同步本地数据库；退出阅读时补存，过期写入不覆盖较新的进度。未导入全文的题录仍明确展示资料状态。

验收证据：evidence/reader-v0111/VERIFICATION.txt。模型交互使用隔离的本地模拟接口；扫描件实际识别效果仍取决于原图质量。

## 0.1.10 · 直接聊天与需求补齐

- **学习伙伴打开即可输入**：默认直接对话，Enter 发送、Shift+Enter 换行；中文输入法选字不触发发送。聊天区独立滚动，输入框保持在底部；图片上传、回复和分支仍可使用。
- 关联课程、临时对话及跨板块操作开关放入“对话选项”；个人记忆设置位于聊天区下方，默认折叠。不选课程不会在后台刷新时自动绑回课程，沿用已有模型设置。
- 论文库无需先打开某篇论文即可提问，支持主动加入多篇参考。学习伙伴里的论文引用可跳转到原文页；同一讨论继承选区，支持明确停止沿用。PDF 文字高亮显示在原文上。
- 超过近期原文预算时，当前分支先生成并核验工作摘要，再回答。摘要保留来源锚点、条件、更正和未解决问题，压缩不删除原文；即使关闭个人记忆自动整理，工作上下文仍可压缩。工作摘要不作为用户个人事实跨会话召回。
- 选中回答片段后点“回复”，只引用该片段；课件旧问答可原对话续聊，不必另开分支。被遗忘的来源不通过引用快照重新进入工作上下文。
- 智能出题会合并下方用户已填的题量、来源、范围、时长等，缺项再补全；顶部快速卡片的显式输入优先。
- 修复概览跳转的展开/聚焦时序，先展开详细设置再聚焦知识点。模块停用的 Skills 不再被对话单独注入。伙伴可新建、调整、移除及撤销计划与课表，检查时间冲突和版本。

验收证据位于 evidence/completion-v0110/VERIFICATION.txt。自动测试采用隔离数据与本地模型模拟接口；安装包另测启动、实际离线 OCR 与源码/包内文件一致性。

## 第一次使用

1. 在“设置与连接”填写 OpenAI 兼容 API 地址、模型 ID、Key。DeepSeek 官方模型使用 `https://api.deepseek.com` 和 `deepseek-flash`。留空单价时只显示 tokens，不给出伪精确费用。
2. 新建课程。只有勾选课程云端授权后，模型才可接收该课程的必要文字或页面图片。关闭授权仍可本地阅读、OCR、记录和排程。
3. 导入 PDF、图片、PPTX 或文本。PDF 在本机生成页图与文字；“识别与核对”先让模型查看代表性页，再分流到文字提取、本地 OCR 或图片模型。PPTX 当前是文字提取，完整版式请先转成 PDF。
4. 选中文字或框选图片区域提问；引用可返回匹配的课件页。生成的复习资料可编辑，导出 Markdown / PDF。
5. 导入作业后提取题目，或报题号收录错题。也可手动录入。核对模糊题干后再记录作答，避免识别错误污染掌握度。
6. 选择知识点生成针对练习或复习卷。默认为 3 题，按掌握情况和可用时间减少题量；连续出错先回顾。生成题经过第二轮模型检查，但不是权威答案保证。
7. 确认答错会创建智能体复习任务并调整其当天安排；固定、锁定和其他用户安排保持不变。所有排程变更可撤销。

## 0.1.4 · 复习提醒与概览直达

- 学习概览新增“待复习与到期待办”：显示到期计划、逾期项目、未排程待办和未安排的错题；点击定位对应计划、待办或具体题目，跨课程时自动切换。
- 计划按开始时间提醒。未排程待办与错题默认在“每日学习开始时间”提醒；已有未来计划的内容不会提前重复提醒。已完成、跳过或删除的项目不再提醒。没有待办关联的错题在最近一次确认独立答对后停止提醒。
- 桌面启动后及每分钟检查一次；系统通知合并发送，同一项目同一天成功提醒后不再重复，重启也保留去重状态。逾期内容次日仍可提醒。点击单项通知直达项目，多项通知打开概览提醒列表。
- “设置与连接 → 学习提醒”可开关系统提醒。默认通知含声音，实际横幅和声音受 Windows 通知与勿扰设置影响；系统通知未显示时仍能从概览查看待处理列表。软件运行或驻留托盘时有效，完全退出、关机后不发送；下次启动补查到期内容。
- 概览的四张统计卡片、今日计划标题、知识点条目都可点击。知识点进入对应题目筛选；计划进入对应日期并高亮。完成按钮只标记完成，不触发跳转。

## 0.1.3 · 选区提问、连续追问与幂的排版

- 数学公式的幂使用底数右上角的真正上标。多位数、负指数和多项式指数使用完整花括号，界面及 PDF 共用公式渲染；代码示例和导入的原始图片保持原样。

- 连续追问：首次回答后，可在弹窗继续提问，无需重新框选；课件图片问答右侧点击“继续追问”进入对话。系统保留原始选区图片、原文来源和前面的问答。关闭窗口或重启后，可从学习助手的历史问答继续；更换选区另起对话。长对话给模型提供最近最多 8 轮（最多约 24000 字符），完整历史仍保存在本地。
- 课件图片：直接拖框，右侧预览选中区域，填写问题后点击“结合资料提问”。图片片段连同资料名、当前页码和页面原文发送给已配置的模型。
- 课件文字、个人错题答案、练习卷已显示的答案、复习资料和助手回答：点击“框选内容”，拖动覆盖文字或公式，再点击“就此选区提问”。也支持直接用鼠标选中文字。弹窗显示选区，填写问题后可原位查看智能体解释。
- 参考答案框选使用页面几何位置提取文字和完整 LaTeX（不截图再 OCR），分式、根式保留完整结构，选区预览可在提交前核对；框选到公式的一部分也会携带整个公式。
- 选区问题绑定课程、来源记录及版本。课件带页码，答案带题干、参考答案、步骤和知识点；问答保存在本课程的学习助手中。切页清空旧图像选区，原文改动后的旧选区会提示重新选择。
- 空白区域不发送；试卷答案在正常可查看后才显示框选入口。移动端提供同一入口，框选模式下触控用于画框，退出框选后恢复滚动。
- 验收：本地模拟模型完成实际 UI → HTTPS 后端 → 模型 → 弹窗回显闭环；不把模拟回复当作本轮真实模型准确率评测。

## 0.1.2 · 数学排版

- 题干、答案、解析、问答和 PDF 使用同一套数学排版规则。修正原先公式渲染器与 CSS/字体版本不匹配的问题。
- 分式采用上下结构；已有 LaTeX 的 \frac / \tfrac 在显示时采用 \dfrac。明确的整式分式（如数学定界符内的 1/2）也显示为上下形式；含糊的混合斜杠表达式不擅自改写数学含义。
- 根式用完整的 \sqrt{...}，分式与根式独立成块。保留公式字号，不压成一行；手机端长公式可横向滚动。
- 增加公式上下、段落、题目及步骤之间的留白。模型生成规则要求多步推导分行、答案和解析分区。
- PDF 使用 A4、18 mm 页边距与 12 pt 正文，公式块避免跨页切断；超长或超高公式会提示分行后再导出，不静默截断。
- 原始题目和作答不因显示格式变化而重写。原始截图中的排版不在此规则中重绘。

已生成并逐页检查“output/pdf/数学排版样张.pdf”；本次证据见“evidence/math-v012/VERIFICATION.txt”。旧版安装包保留。

## 搜索与课表

- Brave Search 使用单独的 Key；未配置时不会冒充联网成功。用户明确指定网页时支持公网网页读取。
- 官网窗口由用户自己登录、完成验证码并进入课表页；提取结果先预览。不替用户提交选课或修改教务系统。
- CSV / XLSX 读取首个工作表，模板列：课程、日期、星期、周次、开始、结束、节次、地点。Excel 日期与时间序列值可转换。填写第 1 周星期一与学期周数后，可展开每周、单双周、范围或离散周次；节次时间由用户配置，停课日期由用户明确填写。具体日期优先于周次，明确起止时间优先于节次。

### 0.1.1 · 学期课表导入

在“每日计划 → 课表与固定安排”导入表格，或点击“添加周期课程”。示例：第 1 周星期一为 2026-10-26，星期为周一，周次为 `1-6(单)`，将生成 10 月 26 日、11 月 9 日、11 月 23 日。单双周按教学周编号计算。

- 周次支持 `每周`、`单周`、`双周`、`1-16(单)`、`1,3,5`、`1-4(单),4-8(双)`。空白与含糊周次先修正，不默认填满学期。
- 起止时间留空时可填 `1-2` 节，并在学校节次时间中逐行输入 `1,08:00,08:45` 等。
- 点击“展开并检查课表”仅预览。预览列出日期、教学周、时间、重复、停课与冲突；输入改变后重新预览，已有安排变化也会要求重新确认。
- 完全重复项跳过；时间冲突需勾选确认。导入作为一个事务写入，遇到错误整批回滚，不覆盖现有课表或计划。
- 最近批次支持整批撤销；有课程已经修改或删除时阻止整批撤销，保留后续编辑。
- 停课日期只做排除；调课到其他日期请手动添加固定安排。真实教务网站仍需另行验收。

本次验证详见 `evidence/semester-v011/VERIFICATION.txt`；0.1.0 安装包与证据保留。

## 手机连接

1. 电脑与手机位于同一局域网，电脑应用保持运行。
2. 电脑下载本机 CA 证书，通过自己的设备传输方式送到手机安装，并核对指纹。iPhone 还需在“关于本机 → 证书信任设置”启用该本机 CA。
3. 扫描二维码，提交配对请求，在电脑点击允许。
4. 如 Windows 防火墙询问，仅允许所需的专用网络；应用端口为 TCP 43127。学校 Wi-Fi 的客户端隔离可能阻止互访。
5. IP 地址变化后重启应用并刷新二维码。电脑可撤销已配对设备。

证书私钥和网站登录会话不包含在学习备份中。手机端不接收模型 Key，也不能配置模型或恢复备份。

## 备份与恢复

每日自动创建无损 ZIP 备份，保留最近 7 份；可以手动备份、下载、恢复。恢复前先备份当前状态，校验文件哈希后写入。恢复不迁移凭据、配对与教务网站会话。

空间低于 5 GB 或磁盘容量的 10% 时暂停大型导入。原始资料不自动删除，不用摘要替换历史原文。

## 0.1.6 · 纸笔复习闭环与指定题型

练习页可直接输入“想练什么”，无需先选知识点；模型解析题型、条件与难度，保留原始要求，模糊请求先补充。支持多种变式和按知识点分配：默认 3 题；较熟练 1 题并逐步升级进阶/综合；最近 3 次有效记录错至少 2 次时目标 5 题、先讲解、受本轮及每日预算限制。未安排目标显示顺延，旧卷不被改写。

纸笔工作台提供带卷号、稳定题号、每题 1 分和可调作答留白的作答卷 PDF，以及独立详细答案 PDF。每次最多 60 页，单文件 30 MB；支持 PNG/JPEG 照片和多页 PDF。原件按哈希保存，重复页合并；同一试卷的同一道题只保留一份当前计分证据，重拍或纠正更新原记录，批次历史保留。

整卷识别、按最终答案评估后必须逐题核对再确认。不做步骤评分。漏拍/模糊不直接计错，可人工校对转写与页码、重新评估；图像接口失败时尝试本地 OCR，初稿强制待核对。独立完成方式默认未说明，不用于提升熟练度。确认后联动错题、证据型记忆和智能体计划；综合题错误先做单知识点诊断。

3 道不同新题独立正确、跨度至少 48 小时且期间无错误可自动较熟练。用户可手动标为已掌握/不熟练或恢复自动评估，冲突只提示不静默覆盖。已巩固错题保留历史。未开始旧卷可生成新版本，已开始旧卷保持不变。模型判断与题目自检不是教师评分，所有确认可纠正。

## 0.1.7 · 输入题型预览与边界修复

直接输入题型后点击“解析题型与预览”，核对知识点与难度，再生成练习或覆盖试卷。两种入口均保留原始要求，复用已确认的题型解析；修改文本、课程或勾选知识点后需重新预览。模糊输入显示补充问题，不出卷。解析本身不更改学习记录。

连续错误的题型会显示参考讲解和确认入口。手动题数仍受时间预算、单知识点诊断与指定难度约束；掌握度与题量在出题时重新计算，不复用旧预览中的学习状态。

## 0.1.8 · 共享个人学习记忆与学习伙伴

“学习记忆”导航合并到“学习伙伴”，原有课程记忆以折叠区保留。课件提问/框选追问与学习伙伴读取、补充、纠正、遗忘同一份记忆，重点记录具体学习卡点、学习偏好、目标与有时效的近况。自述困难与已确认作答分开，不据此增加错误次数或改写正式掌握度。

设置中分别确认伙伴对话/图片发送、必要记忆片段发送，数据存于本机。自动整理仅处理开启后新对话；旧聊天批处理单独确认。后台整理有每日调用上限（默认 12 次，含独立核验），每批最多 6 轮；失败最多尝试两次并保留原文。原文证据、候选记忆、当前记忆、摘要、遗忘规则分别保存。学习偏好可跨课程调用，课程薄弱点按课程隔离。

长对话使用最近最多 8 轮原文、已核验摘要和相关记忆，不静默声称完整回忆；摘要保留目标、条件、更正、决定、未解决问题及下一步。摘要模型核验属于模型自检，并非事实准确率保证。

图片支持 PNG/JPEG，每次最多 4 张、每张 12 MB；对话中预览，继续追问沿用原图，新对话不带入。识图需所配置模型支持图像输入，测试使用模拟图像接口。图中内容不直接作为用户个人事实。

对话指令：`记住：内容`、`纠正记忆：旧内容 => 新内容`、`忘记：内容`、`连原始记录一起删除：内容`（确认范围后执行）、`这次不要记忆`。临时对话不提取长期记忆或跨会话摘要；当前对话仍保留工作上下文。删除与更正规则随备份保存，恢复旧备份时与当前遗忘规则合并，旧备份文件本身可能仍含原文。

容量默认 100 MB（聊天文字、摘要、记忆；不含图片和课件原件）；只清理超过默认 30 天且已核验摘要的旧聊天原文，固定重要记忆对应原文保留；清理后标注原文已清理。受保护内容仍超额时保留并提示。每日关心仅软件运行时在应用内展示，默认每天最多一次，22:00–08:00 静默（时区可随设置保存），与系统复习提醒分开。


## 0.1.9 · 三种练习模式、论文阅读与可操作的学习伙伴

同一个“练习与试卷”入口内分为三个操作单元：
- **快捷练习**：页面内单选/多选，自动保存选项草稿，逐题提交并显示分步解析。默认约 80% 针对薄弱点、20% 为当前课程拓展；所有设置选填，已填写值优先。正式提交才更新学习证据，提示、看答案、蒙对与独立作答分开。本轮题目固定，下一轮按掌握情况调节题量与难度。
- **专项练习**：保留原有题型输入、解析预览、变式、来源选择与下载/上传评估；顶部可直接按记忆生成，详细手动设置默认折叠。
- **复习试卷**：独立显示出卷与历史试卷，保留作答卷/参考答案分别下载、模拟考试和上传评估。可以自己核对答案并报告错误/蒙对/未做题号；只有明确勾选全卷核对时才更新其余题目。自评正确不直接当作独立掌握，可撤销本次核对。

**论文库**：Crossref 标题/作者/主题/DOI 检索，相关度/引用次数/年份排序，批量收藏，导入本地 PDF 或网页/DOI/PDF 链接。引用次数注明 Crossref 来源与查询时间，缺失显示暂无数据；同行评审和更正/撤稿状态不伪造。网页只有链接或摘要时明确标识资料范围，全文受来源站可访问性影响。

**阅读模式**：PDF 原文＋右侧连续对话，可切换纯阅读/沉浸阅读，调整对话宽度；文本选区、图表框选、OCR 核对、笔记、书签、高亮与阅读进度保留。回答出处用小编号，核验引用原文后才能定位。多篇论文可在论文库对话中手动加入参考。

**学习伙伴**：直接文本/图片对话、回复旧回答、从回答或选中片段开启分支、手动跨分支引用。分支仅继承分叉点以前的祖先上下文；不同分支不自动互相混入。共享学习偏好和薄弱点记忆，近期原文＋已核验摘要控制上下文，摘要缺失时如实标注。原文删除同步清理分支引用快照。

**实际操作**：伙伴可创建/编辑待办、课程、笔记、学习记忆和计划，整理论文与题目，生成练习、检索论文、自行报错题号、运行已导入脚本。普通修改显示实际操作回执和撤销；锁定计划与重大删除集中确认，后续修改冲突时阻止覆盖。成绩不能由讨论内容推定，掌握自评与正式作答分开。

**Skills**：在设置与连接中导入 SKILL.md、文件夹或 ZIP。按模块启用、自动匹配或手动指定，保留最近三个旧版本；导入本身不运行代码。Python/Node 脚本可显式运行，使用独立任务目录，显示真实输出/产物，支持任务取消和 60 秒超时。脚本具有本机程序权限，非沙箱；Python 及第三方依赖需本机已安装，可指定解释器路径。

可复用的学习伙伴请求：
```text
根据我的当前课程、最近的错题和学习薄弱点，安排下一轮练习。
我已填的范围、题数和难度优先；没填的项目由你补全。
基础熟练后减少重复、增加综合变式；连续出错时先分步讲解。
不要把看过答案或蒙对当作独立掌握。说明实际完成的修改。
```

验收使用隔离临时数据和本地模拟模型；不使用现有个人数据或账号 Key。真实 Crossref 元数据检索单独联通验证。模型生成质量与视觉识别效果取决于用户配置的真实服务，模拟验收不代表真实模型准确率。
